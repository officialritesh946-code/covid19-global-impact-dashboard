# Project Submission Checklist

## Required deliverables
- [x] Cleaned dataset with documented assumptions
- [x] 3–5 key insights in plain language
- [x] Dashboard image with trend, country and region views
- [x] Executive summary PDF
- [x] README with project question, methodology and limitations
- [x] Reproducible Python script
- [x] Jupyter notebook structure

## Before GitHub submission
1. Create a new public/private repository named `covid19-global-impact-dashboard`.
2. Upload all project files and the `raw_data/` folder if the internship permits redistribution of the source data.
3. If the source dataset has redistribution restrictions, upload only the cleaned/derived data and link to the original source instead.
4. Add `README.md` as the repository front page.
5. Open the dashboard PNG and verify that labels are readable.
6. Mention the important limitation: the supplied dataset has no vaccination fields.
